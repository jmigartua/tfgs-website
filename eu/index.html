Fisikako Gradu Amaierako Lanak

Fisikako Gradu Amaierako Lanak zuzentzen ditut Euskal Herriko Unibertsitatean, eta webgune hau haien erregistroa da.

Berrogeita sei Gradu Amaierako Lan 2011tik hona, euskaraz, gaztelaniaz eta ingelesez idatziak: ikasleek zer aztertu duten, datorren ikasturterako zer proposatzen den, eta zurea nola planifikatu, idatzi eta defendatu. Datu-base egiaztatu bakar batetik mantendua; lan bakoitza bere egileari egozten zaio, eta kalifikazioak ez dira inoiz argitaratzen.

Zure GrALa prestatzea

Eskuliburua →

Bost zatiko gida Fisikako laugarren mailako ikasleentzat, gaia aukeratzetik defentsa aurreko azken zerrendaraino.

I. ZATIA

Proiektua garatzea

Helburuak, gaiaren aukeraketa, literaturaren berrikuspena, plan metodologikoa, lan praktikoa, etika.

II. ZATIA

Txostena idaztea

Egitura, idazketa akademikoa, IEEE aipuak, idazketa-tresnak, Git bidezko bertsio-kontrola.

III. ZATIA

Aurkezpena eta defentsa

Hitzaldia eraikitzea, jendaurrean hitz egitea, galderei erantzutea, ulermena erakustea.

IV · V. ZATIAK

Tresnak, zerrendak eta gehigarriak

VS Code, Git eta GitHub, Quarto, LaTeX, erreproduzigarritasuna eta azken zerrenda.

Materia kondentsatuan, sistema konplexuetan edo fisikaren didaktikan GrAL bat egitea pentsatzen ari zara?

Zientzia eta Teknologia Fakultateko (EHU) Fisika Saileko katedraduna naiz. Materia kondentsatuaren fisikan, fase-trantsizio estrukturaletan eta fenomeno kritikoetan ikertzen dut, eta arlo horietan eta proposamenetan ikusten duzun fisika sozial eta konputazionalean zuzentzen ditut lanak. Idatzi josu.igartua@ehu.eus helbidera, interesatzen zaizunari buruzko paragrafo batekin.
