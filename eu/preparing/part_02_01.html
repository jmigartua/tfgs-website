II. Zatia – Entregagarriaren (Txostena) Prestaketa

2.1 GRAL Txostenaren Egitura Xehatua

Fisikako GRAL txosten ondo egituratu batek honako hauek izan behar ditu:

Sarrera

  • Motibazioa eta Testuingurua: Aurkeztu argi eta garbi aurrekari zientifikoak, garrantzia eta zure azterketaren motibazioa.
  • Ikerketa Galderak eta Helburuak: Adierazi esplizituki jorratu nahi dituzun ikerketa-galderak eta helburu espezifikoak.
  • Egituraren Ikuspegi Orokorra: Deskribatu laburki zure dokumentuaren antolaketa.

Esparru Teorikoa

  • Literaturaren Berrikuspena: Aztertu kritikoki aurretiazko ikerketak, ekarpenak eta mugak nabarmenduz.
  • Funtsezko Kontzeptuak eta Teoriak: Definitu eta testuinguruan jarri argi eta garbi Fisikako teoria, eredu eta ekuazio garrantzitsuak.

Metodologia

  • Prozedura Esperimentalak: Eman konfigurazio esperimentalen, tresnen eta erabilitako materialen deskribapen zehatzak.
  • Eredu Konputazionalak: Azaldu argi eta garbi simulazioak, softwarea (Python, MATLAB, R), algoritmoak eta formulazio matematikoak.
  • Datu Bilketa Metodoak: Deskribatu datuak eskuratzeko eta kudeatzeko metodoak.

Emaitzak

  • Datuen Aurkezpena: Erabili irudiak, taulak eta grafikoak zure aurkikuntzak argi eta garbi erakusteko.
  • Analisi Teknikak: Azaldu analisi-metodoak (proba estatistikoak, metodo konputazionalak).

Eztabaida eta Analisia

  • Interpretazioa: Lotu zure emaitzak jatorrizko ikerketa-galderekin, ereduak, anomaliak eta inplikazioak aztertuz.
  • Konparazioa: Konparatu kritikoki zure aurkikuntzak aurretiazko ikerketekin eta iragarpen teorikoekin.

Ondorioa

  • Aurkikuntzen Laburpena: Laburtu argi eta garbi emaitza nagusiak eta Fisikaren arloan duten garrantzia.
  • Mugak eta Etorkizuneko Lana: Eztabaidatu muga metodologikoak eta iradoki etorkizuneko esploraziorako arloak.

Bibliografia

  • IEEE Aipamen Araua: Formateatu erreferentzia guztiak IEEE jarraibideen arabera, zehaztasuna eta osotasuna bermatuz.

Eranskinak

  • Material Osagarria: Sartu datu gehigarriak, kode konputazionaleko script-ak (argi eta garbi iruzkindutako Python edo R kodea), prozedura esperimentalak eta deribazio edo froga matematiko zehatzak.

2.2 Idazketa Akademikoaren Jardunbide Egokiak

  • Argitasuna eta Zehaztasuna: Mantendu fluxu logikoa eta koherentzia.
  • Idazketa Teknikoa: Definitu argi eta garbi termino espezializatu guztiak lehen aldiz erabiltzean; gutxitu anbiguotasuna.
  • Plagioa Saihestea: Parafraseatu eta aipatu iturriak behar bezala; erabili aipu zuzenak neurriz.
  • Zuzenketa eta Edizioa: Berrikusi aldizka eta eskatu ikaskideen iritzia; kontuan hartu Grammarly edo LanguageTool bezalako gramatika-egiaztapen tresnak.

2.3 IDE batekin Idaztea

Visual Studio Code (VS Code)

  • Konfigurazioa: Instalatu VS Code eta funtsezko plugin-ak.
  • Produktibitaterako Plugin-ak: Markdown All-in-One, GitLens, LaTeX Workshop, Code Spell Checker, Prettier formatu koherenterako.
  • IDE Alternatiboak: RStudio, Positron eta idazketa zientifikorako dituzten ezaugarri espezifikoen sarrera laburra.

2.4 Quarto Ekosistema

  • Quarto-ra Sarrera: Markdown eta kode exekutagarria konbinatzen dituen idazketa akademikorako tresna integratua.
  • Txostenak Idaztea: Python edo R kode-zatiak txertatzeko eta exekutatzeko urratsez urratseko orientazioa.
  • Esportazio Formatuak: Sortu irteera profesionalak PDF (LaTeX txantiloiak), HTML edo web formatu interaktiboetan.

2.5 Bertsio Kontrola

  • Git Oinarriak: Git biltegiak konfiguratzeko, aldaketak egiteko (commit), adarrak sortzeko eta bat egiteko urratsez urratseko gida.
  • Lankidetza Lan-fluxua: GitHub erabiltzeko jardunbide egokiak ikaskideen lankidetzarako eta bertsioen segurtasun-kopiarako.
  • VS Code-rekin Integrazioa: Zure IDE barruan bertsio-kontrolaren ezaugarriak erabiltzea zure proiektuaren berrikuspenak modu errazean kudeatzeko.

2.6 Inguruneak eta Exekuzioa

  • Ingurune Birtualak: Python (venv, conda) edo R (renv) inguruneak sortzeko eta kudeatzeko argibideak.
  • Plataforma Anitzeko Erreproduzigarritasuna: Zure proiektua Windows, macOS eta Linux-en ondo funtzionatzen duela ziurtatzeko estrategiak.
  • Mendekotasunen Kudeaketa: Zure ingurune konputazionala plataforma desberdinetan zehaztasunez dokumentatzeko (requirements.txt, environment.yml) eta erreproduzitzeko teknikak.

II. Zatia – Entregagarriaren (Txostena) Prestaketa

2.1 GRAL Txostenaren Egitura Xehatua

Fisikako GRAL txosten eraginkor batek irakurleak argi eta garbi gidatuko ditu zure ikerketan zehar, sarreratik ondorioetara. Hasi zure txostena motibazioa eta testuingurua aurkeztuz, argi eta garbi azalduz zergatik den garrantzitsua zure azterketa Fisikaren eremu zabalagoan. Aurkeztu zure ikerketa-galderak eta helburu espezifikoak, zehazki zer ikertu edo lortu nahi duzun adieraziz. Eman irakurleei zure dokumentuaren egituraren ikuspegi orokor laburra, atal bakoitzak zer eduki biltzen duen argituz.

Esparru teorikoaren atalean, egin literaturaren berrikuspen sakon eta kritikoa, zure ikerketari dagozkion aurretiazko azterlanak zehaztuz. Nabarmendu argi eta garbi ekarpenak, identifikatu mugak eta adierazi zure ikerketak hutsune horiei nola aurre egin nahi dien. Definitu eta testuinguruan jarri funtsezko kontzeptu fisikoak, teoriak eta ereduak, zure irakurlea zure analisiaren gainerakoan zehar gidatuko duen oinarri sendo bat ezarriz.

Zure metodologiak zehatz-mehatz dokumentatu behar du zure ikerketa-ikuspegia, esperimentala, teorikoa edo konputazionala izan. Esperimentuak egiten badituzu, eman zure konfigurazioen deskribapen argi eta zehatza, tresneria, kalibrazioa eta neurketa-prozedurak barne. Ikerketa konputazionalerako, azaldu zure ereduak argi eta garbi, erabilitako software espezifikoa (hala nola Python, MATLAB edo R), inplementatutako algoritmoak eta erabilitako formulazio matematikoak aipatuz. Gainera, adierazi argi eta garbi zure datu-bilketa metodoak, zure ikerketan zehar datuak nola eskuratu, prozesatu eta kudeatu dituzun deskribatuz.

Emaitzen atalak zure aurkikuntzak argi eta logikoki aurkeztu behar ditu. Erabili taulak, irudiak eta grafikoak eraginkortasunez zure datuak laburtzeko eta bisualki ilustratzeko. Elementu bisual bakoitza arretaz etiketatu behar da eta testutik independenteki ulergarria egiten duen oin-ohar deskribatzaile batekin lagundu. Zehaztu eta justifikatu aukeratutako datu-analisirako metodoak, erabilitako proba estatistikoak edo teknika konputazionalak barne.

Eztabaida eta analisiaren atalean, interpretatu zure emaitzak modu integralean, esplizituki lotuz zure ikerketa-galderekin eta esparru teorikoarekin. Arakatu identifikatutako eredu edo anomaliak, azalpen argiak emanez eta zure aurkikuntzak aurretiaz ezarritako teoriekin eta emaitza enpirikoekin lotuz. Konparatu eta kontrastatu zure emaitzak kritikoki aurretiazko ikerketekin, bai berrespenak bai desadostasunak eztabaidatuz.

Amaitu zure txostena emaitza nagusiak laburki laburtuz eta Fisikan duten garrantzia eta esanahia azpimarratuz. Eztabaidatu esplizituki zure ikerketan aurkitutako mugak, zintzotasunez hausnartuz muga metodologikoen edo balizko alborapenen inguruan. Adierazi argi eta garbi etorkizuneko ikerketarako iradokizunak, zure proiektuak ireki edo erantzun gabe utzi dituen arloak edo galderak zehaztuz.

Ziurtatu zure bibliografiak zorrotz betetzen dituela IEEE aipamen-arauak, iturri guztien erreferentzietan osotasuna eta zehaztasuna egiaztatuz. Sartu material osagarri garrantzitsuak eranskinetan, hala nola kalkulu zehatzak, kode konputazionaleko script-ak (argi eta garbi iruzkinduta eta egituratuta), datu esperimental gordinak eta azalpen metodologiko hedatuak.

2.2 Idazketa Akademikoaren Jardunbide Egokiak

Fisikako kalitate handiko idazketa akademikoak argitasuna, zehaztasuna eta koherentzia logikoa eskatzen ditu. Idatzi argi eta garbi, zure argudioak logikoki egituratuz ulermena errazteko. Saihestu beharrezkoa ez den konplexutasuna edo anbiguotasuna, termino espezializatu guztiak argi eta garbi definituz lehen aldiz aurkezten direnean. Bete zorrotz IEEE aipamen-gidalerroak, iturri guztiak zehaztasunez eta koherentziaz aipatzen direla ziurtatuz, ekarpenak behar bezala aitortzeko eta plagioa saihesteko.

Gutxitu jargoia, zure xede-irakurle akademikoen mailari dagokion hizkuntza zehatza erabiliz. Zuzendu aldizka zure eskuizkribua irakurgarritasuna, argitasuna eta zehaztasuna hobetzeko. Eskatu iritzia ikaskideei edo zure zuzendariari, kritika eraikitzaileak integratuz zure lanaren zorroztasuna eta argitasuna hobetzeko. Erabili Grammarly edo LanguageTool bezalako gramatika-egiaztapen tresnak baliabide gehigarri gisa, ahaztutako akatsak edo esaldi anbiguoak identifikatzeko.

2.3 IDE batekin Idaztea

Visual Studio Code (VS Code) oso gomendagarria da kodeketa eta idazketa eraginkortasunez integratzeko. Hasi VS Code bere webgune ofizialetik instalatzen, eta ondoren pertsonalizatu zure konfigurazioa funtsezko plugin-ekin produktibitatea optimizatzeko. Markdown All-in-One, GitLens, LaTeX Workshop, Code Spell Checker eta Prettier bezalako plugin-ek formatu koherentea, argitasuna eta antolaketa mantentzen laguntzen dizute idazketa-prozesu osoan zehar.

RStudio edo Positron bezalako IDE alternatiboak ere onuragarriak izan daitezke zure behar espezifikoen arabera, batez ere zure proiektuak analisi estatistiko zabala edo R-n oinarritutako simulazioak baditu. Arakatu laburki haien indarguneak eta kontuan hartu zure proiektuaren eskakizun espezifikoekin bat datorren IDE bat aukeratzea.

2.4 Quarto Ekosistema

Quarto idazketa akademikorako tresna oso indartsua da, Markdown eta kode exekutagarriko zatiak ezin hobeto integratzen dituena. Quartok txosten integral eta erreproduzigarriak idaztea errazten du, zure prozesu analitikoen dokumentazio argia ahalbidetuz testu narratiboarekin batera. Txertatu eta exekutatu Python, R edo Julia kodea zuzenean zure txostenetan emaitzak, irudiak eta analisiak dinamikoki sortzeko, erreproduzigarritasuna eta gardentasuna hobetuz.

Erabili Quartoren esportazio-funtzionalitate polifazetikoak kalitate profesionaleko dokumentuak ahaleginik gabe sortzeko hainbat formatutan, hala nola PDF pertsonalizatutako LaTeX txantiloiak erabiliz, HTML web-eduki interaktiboetarako edo dokumentu interaktibo dinamikoak. Quartoren ikuspegi integratuak asko errazten du irteera akademiko argiak, erreproduzigarriak eta bisualki erakargarriak sortzeko prozesua.

2.5 Bertsio Kontrola

Bertsio-kontrolaren erabilera eraginkorra, bereziki Git, ezinbestekoa da zure GRAL proiektua eraginkortasunez kudeatzeko. Konfiguratu Git biltegi bat proiektuaren hasieran aldaketak kudeatzeko, aurrerapena argi eta garbi jarraitzeko eta beharrezkoa bada aurreko bertsioetara itzultzeko. Egin aldaketen commit-ak aldizka mezu esanguratsuekin, egindako eguneraketak edo doikuntzak argi eta garbi adieraziz. Kudeatu proiektuaren aldakuntzak eta esperimentuak adar bereiziak erabiliz, adar nagusiarekin bat eginez egiaztatu eta onartu ondoren.

Lankidetzan aritu eraginkortasunez ikaskideekin edo zure zuzendariarekin GitHub erabiliz; horrek talde-lan leuna, gatazken konponbidea eta proiektuaren bertsioen segurtasun-kopia errazten ditu. Git zure IDEan integratzeak (VS Code adibidez) bertsioen kudeaketa are gehiago errazten du, zure berrikuspenen eta lankidetza-lan-fluxuen jarraipena zuzenean zure edizio-ingurunetik ahalbidetuz.

2.6 Inguruneak eta Exekuzioa

Zure ingurune konputazionalaren erreproduzigarritasuna eta koherentzia bermatzea ezinbestekoa da zure GRALaren sinesgarritasunerako. Ezarri ingurune birtual isolatuak Python (venv), Conda edo R (renv) erabiliz, software-bertsioen eta mendekotasunen kontrol argia mantentzeko. Zure konfigurazio konputazionalaren dokumentazio zehatza, requirements.txt edo environment.yml bezalako fitxategiak erabiliz, kritikoa da zure analisia plataforma informatiko desberdinetan erreproduzitzeko.

Berretsi zure ingurune konputazionalak fidagarritasunez funtzionatzen duela Windows, macOS eta Linux-en, sistema desberdinetan ondo probatuz. Dokumentatu argi eta garbi instalazio-prozedurak, ingurune-konfigurazioak eta mendekotasunak. Alderdi horiek modu proaktiboan kudeatzeak bermatzen du ebaluatzaileek edo etorkizuneko ikertzaileek zure emaitzak zehaztasunez eta fidagarritasunez erreplikatu ahal izango dituztela.
