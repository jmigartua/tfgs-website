I. Zatia – GRAL Proiektuaren Garapena

1.1 Proiektua Ulertzea

Zure Gradu Amaierako Lanaren (GRAL) helburua Fisikako ikasketetan zehar eskuratutako ezagutzak, gaitasun analitikoak eta trebetasun metodologikoak aplikatzeko gaitasuna erakustea da. Zure interes akademikoekin eta karrera-helburuekin bat datorren gai bat aukeratzea ezinbestekoa da. Hausnartu arretaz zure indargune pertsonalei eta benetan motibatzen zaituzten gaiei buruz. Kontuan hartu aurretiazko ideiak irakasleekin edo balizko zuzendariekin eztabaidatzea zure aukera fintzeko. Definitu argi eta garbi zure ikerketa-galdera eta helburuak zure proiektuaren norabidea eta irismena bideratzeko.

1.2 Prestaketa Teorikoa

Hasi literaturaren berrikuspen sakon batekin esparru teoriko sendo bat ezartzeko. Horrek funtsezko kontzeptuak, aurretiazko ikerketak eta zure ikerketak beteko dituen hutsuneak identifikatzea dakar. Erabili datu-base akademikoak, hala nola Google Scholar, JSTOR eta Scopus, bilaketa integralak egiteko. Kudeatu zure literatura sistematikoki Zotero, Mendeley edo BibTeX bezalako erreferentzia-tresnak erabiliz, aipamenen kudeaketa eta bibliografiaren sorrera errazteko. Laburtu eta ebaluatu kritikoki azterlan garrantzitsuak, aurkikuntza esanguratsuak, erabilitako metodologiak eta identifikatutako mugak nabarmenduz. Prestaketa honek zure ikerketa egungo ulermen zientifikoan oinarrituta egotea eta lehendik dagoen ezagutzari ekarpen esanguratsua egitea bermatzen du.

1.3 Plangintza Metodologikoa

Zehaztu argi eta garbi zure ikuspegi metodologikoa, konfigurazio esperimentalak, eredu konputazionalak, kalkulu teorikoak edo horien konbinazio bat barne hartuko dituen zehaztuz. Garatu proiektuaren kronograma errealista eta egituratua, etapa bakoitzerako mugarri argiak ezarriz (literaturaren berrikuspena, esperimentuak/simulazioak, datuen analisia, idazketa-faseak). Mantendu komunikazio eraginkorra zure zuzendariarekin aldizkako bileren edo eguneratzeen bidez, lerrokatzea eta orientazio egokia bermatuz. Aurreikusi balizko oztopoak eta sartu kontingentzia-planak zure kronograman ezusteko erronkei aurre egiteko.

1.4 Lan Praktikoa

Eskaini denbora nahikoa zeregin praktikoei, artikulu zientifikoak irakurtzea, hasierako zirriborroak idaztea, simulazioak egitea (adibidez, Python edo R script-ak datuen analisirako), laborategiko esperimentuak edo landa-behaketak barne. Dokumentatu jarduera guztiak zehatz-mehatz, datak, metodoak eta emaitzak argi eta garbi adieraziz. Eguneratu aldizka ikerketa-eguneroko bat edo erregistro digital bat zure aurrerapena, aurkitutako arazoak eta inplementatutako irtenbideak jarraitzeko. Dokumentazio honek txostenaren idazketa eta analisia nabarmen erraztuko ditu. Berrikusi aldizka zure emaitzak zure zuzendariarekin zehaztasuna eta fidagarritasuna bermatzeko. Ziurtatu datuen kudeaketa eta biltegiratze egokia, segurtasun-kopia digital antolatuak mantenduz datuak galtzea saihesteko.

1.5 Gogoeta Etikoak

Ziurtatu zure ikerketari dagozkion estandar etiko guztiak betetzen direla, batez ere subjektu esperimentalak, datu sentikorrak edo ingurumen-gogoetak tartean badaude. Ezagutu erakundeko etika-gidalerroak, beharrezko baimenak eta baimen informatuak lortuz hala badagokio. Dokumentatu argi eta garbi gogoeta etikoek nola eragin duten zure ikerketa-diseinuan eta praktiketan.

II. Zatia – Entregagarriaren (Txostena) Prestaketa

2.1 GRAL Txostenaren Egitura

GRAL txostenak egitura argi eta logikoa jarraitu behar du:

  • Sarrera: Aurkeztu zure ikerketa-gaia, motibazioa, helburuak eta ikerketa-galderak.
  • Esparru Teorikoa: Eztabaidatu zure gaiari dagozkion lehendik dauden teoriak, ereduak eta aurretiazko ikerketak.
  • Metodologia: Deskribatu zure ikerketa burutzeko erabilitako metodoak eta ikuspegiak.
  • Emaitzak: Aurkeztu argi eta garbi zure aurkikuntzak irudi, taula eta grafiko egokiekin.
  • Eztabaida eta Analisia: Interpretatu zure emaitzak, aurretiazko azterlanekin alderatuz eta ikerketa-galderak jorratuz.
  • Ondorioa: Laburtu funtsezko aurkikuntzak, mugak eta iradoki etorkizuneko ikerketarako bideak.
  • Bibliografia: Zerrendatu aipatutako iturri guztiak koherentziaz IEEE aipamen-arauak erabiliz.
  • Eranskinak: Sartu material osagarria, datu gordinak, kode-scriptak edo kalkulu zehatzak.

2.2 Idazketa Akademikoaren Jardunbide Egokiak

Bilatu argitasuna, zehaztasuna eta koherentzia zure idazketan. Egituratu zure argudioak logikoki, anbiguotasuna saihestuz. Jarraitu IEEE aipamen-gidalerroak koherentziaz iturriak aitortzeko eta plagioa saihesteko. Erabili hizkuntza tekniko argia, jargoia gutxituz beharrezkoa ez bada. Zuzendu aldizka zure zirriborroak eta eskatu iritzia ikaskideei edo zure zuzendariari irakurgarritasuna eta zorroztasuna hobetzeko.

2.3 IDE batekin Idaztea

Erabili Visual Studio Code (VS Code) kodea eta testua konbinatzen dituen idazketa-esperientzia integratu baterako:

  • Instalazioa: Deskargatu eta instalatu VS Code webgune ofizialetik.
  • Funtsezko Luzapenak: Markdown All-in-One, LaTeX Workshop, GitLens produktibitatea hobetzeko.
  • Alternatibak: RStudio, Trae, Positron, bakoitzak indargune espezifikoak eskainiz zure kodeketa eta idazketa beharren arabera.

2.4 Quarto Ekosistema

Quarto idazketa akademikorako tresna indartsua da:

  • Markdown Integrazioa: Idatzi txosten integralak narratiba eta kodea konbinatuz.
  • Kodea Txertatzea: Txertatu kode-zatiak (Python, R, Julia) zuzenean zure dokumentuetan.
  • Esportazio Formatuak: Sortu irteerak PDF, HTML eta dokumentu interaktiboetan ahaleginik gabe.

2.5 Bertsio Kontrola

Ulertu eta erabili Git eraginkortasunez:

  • Git Oinarriak: Sortu biltegiak, kudeatu commit-ak, adarrak eta bat-egiteak.
  • Lankidetza eta Segurtasun-kopia: Erabili GitHub ikaskideekin lankidetzan aritzeko eta bertsioen segurtasun-kopiak mantentzeko.
  • VS Code-rekin Integrazioa: Erabili integratutako tresnak eta luzapenak zure lan-fluxua arintzeko.

2.6 Inguruneak eta Exekuzioa

Kudeatu ingurune konputazionalak erreproduzigarritasuna bermatzeko:

  • Ingurune Birtualak: Sortu Python ingurune isolatuak (venv), R inguruneak (renv) edo Conda inguruneak (conda).
  • Plataforma Anitzeko Erreproduzigarritasuna: Berretsi exekuzio koherentea Windows, macOS eta Linux-en.
  • Mendekotasunen Kudeaketa: Dokumentatu eta kudeatu argi eta garbi mendekotasunak (requirements.txt, environment.yml).

Gida integral honek argitasuna eta sakontasuna bermatzen ditu zure GRALa prestatzeko. Jakinarazi iezadazu III. Zatiarekin jarraitzeko prest zauden, edo xehetasun gehiago sartu nahi dituzun.
