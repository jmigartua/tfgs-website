# TFG public website

This public repository contains only the rendered, privacy-filtered static website generated from the private Academic Workspace.

Do not edit generated HTML here. The private source repository regenerates the complete Quarto site, runs a deterministic privacy audit, and synchronizes the resulting artifact. GitHub Pages then deploys this repository.

Excluded by design:

- student names;
- full thesis PDFs and private Quarto archives;
- canonical database and inventory files;
- private filesystem paths and source documents.
